SGHMS WADALA - COMPLETE WEBSITE DEMO
====================================

This package is a complete static school website demo.

START:
1. Extract the ZIP.
2. Open index.html in Chrome/Edge.
3. No server, database or internet connection is required for the demo.

About
Leadership
Academics
Campus Life

FILES:

- js/script.js         Mobile menu, gallery lightbox, demo form, back-to-top
- assets/              Logo, campus image and placeholder photos
- pages/               All inner pages

IMPORTANT:
All names, messages, numbers, contact details, dates and images are DUMMY PLACEHOLDERS.
Replace them with official school information before final publishing.

The Contact form is frontend-only. It does not send email until connected to a backend/email service.

The website is designed mobile-first and should be tested on Android/iPhone screen sizes before final delivery.
